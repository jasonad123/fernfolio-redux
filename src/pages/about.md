## What is Fernfolio Redux?

An [Eleventy](https://www.11ty.io/) theme designed to simplify the process of creating a beautiful portfolio and blog. Tightly integrated with [Decap CMS](https://decapcms.org/) for flexible, Git-powered content management.

### Why is it a 'redux'? What happened to the original Fernfolio?

This project is an overhaul/update/upgrade of the original [Fernfolio](https://github.com/TylerMRoderick/fernfolio-11ty-template) project. I loved the design but the original developer decided to archive it in 2025, so with the power vested in me, I picked right back up.

### How do I edit content?

Once your site is deployed and configured, add `/admin` to the end of the url (not using localhost) and hit refresh. From there, you should be able to login and see see the content management dashboard. You should be able to change most content here (e.g. page text, images, logo, articles, projects, etc.).

### Further customizations

If you want to take your customizations further, you will need to modify the project source code. Some customizations, like changing theme colors and fonts, are straightforward (those can be modified in the `variables.scss` file). Other customizations will require more in-depth solutions.

If you get stuck or just have a question, feel free to create a [Github issue](https://github.com/jasonad123/fernfolio-redux/issues) and I will try to point you in the right direction.
